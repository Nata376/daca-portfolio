## 🚀 Peaprojekt: UrbanStyle.ltd Analüütika

**UrbanStyle.ltd** on kiiresti kasvav moe e-kaubanduse bränd (käive €3M, ~45 töötajat Tallinnas, Tartus ja Pärnus). Ettevõttel oli üle 10 000 kaootilise müügikande, mis põhjustasid valesid finantsraporteid, ebaefektiivset laohaldust ning sihhitut turundust.

### Peamised Tulemused & Äriline Mõju:
* 📉 **1.46M € finantskorrektsioon:** Tuvastasin ja eemaldasin SQL-i aknafunktsioonide abil 847 dubleeritud tehingukannet.
* 🎯 **VIP-segmendi tuvastamine:** Analüüsisin 2159 unikaalset klienti ja eristasin **424 VIP-klienti**, kes toovad sisse **1 111 362 € (38.65% kogukäibest)**.
* ⚡ **18% laokulude vähendamine:** Laoanalüütika abil optimeeriti laovarusid, säästes hinnanguliselt **18 000 € aastas**.
* ⏱️ **4 tundi/nädalas säästetud tööaega:** Ehitasin GitHub Actionsiga automaatse pipeline'i, mis uuendab andmeid ilma käsitööta.
